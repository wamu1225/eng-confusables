call を使った紛らわしい熟語・句動詞

call の中心イメージ「声を出して呼ぶ」が、続く前置詞・副詞でどう枝分かれするかをまとめたハブページ。

call の中心イメージ

call は「呼ぶ・叫ぶ」が核です。人や物事に対して声（あるいはそれに相当する働きかけ）を向けるという原義から、要求・指名・取り消し・電話といった意味が分かれます。

熟語前置詞・副詞のイメージ中心的な意味
call forfor（目的に向けて求める）～を必要とする・要求する
call onon（対象に接触・働きかける）～を指名する・訪問する
call offoff（離脱・無効化）～を取り消す
call upup（上方へ呼び上げる）電話で呼び出す・徴兵する

call for は「状況が～を求めている」という無生物主語でよく使われ、call on は「特定の人に狙いを定めて働きかける」という指名・訪問の意味になります。call off は「進行中の予定を切り離して無効にする」イメージで、call up は「相手を呼び出して手元に引き上げる」ことから電話にも軍への招集にも使われます。

call の熟語ペア一覧

  • call for と call on — call for は「〜を必要とする・要求する」、call on は「〜に働きかける・訪問する」。主語が「状況」か「人」かで見分けられます。
  • call off と call up — call off は「（予定）を中止する」、call up は「電話をかける・記憶を呼び起こす・招集する」。離脱と呼び出しでイメージが正反対です。
