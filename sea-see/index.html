sea と see

同音 /siː/。sea「海」（名詞）、see「見る・分かる」（動詞）。意味とスペルで判断する同音異義語。

音は同じ、意味とスペルで見分ける

sea と see は同じ発音 /siː/（同音異義語）。意味とスペルで決めます。

  • sea … /siː/ 名詞「海」。
  • see … /siː/ 動詞「見る・見える・分かる・会う」。see-saw-seen。
語発音品詞・中心の意味例文
sea/siː/名詞：海We swam in the sea.（私たちは海で泳いだ）
see/siː/動詞：見る・分かるI can see the mountains from here.（ここから山が見える）

sea の慣用表現で広げる

sea は比喩表現でもよく使われます。at sea（途方に暮れて・混乱して＝本来「海上で」から転じた意味）、sea level（海抜）、the high seas（公海）のように、地理的な意味と比喩的な意味の両方を持ちます。

see の句動詞で広げる

see は句動詞のバリエーションが豊富です。see through ~（〜を見抜く）、see off（見送る）、see to ~（〜を取り計らう）のように前置詞・副詞と組み合わせて意味が広がります。また I see. は「見える」ではなく「なるほど・分かりました」という相づちとして日常会話で非常によく使われます。

よくある誤用

注意I can see fish swimming in the see. は誤りです。水の「海」は名詞の sea（I can see fish swimming in the sea.）。
注意Let's sea a movie tonight. も誤りです。「見る」は動詞の see（Let's see a movie tonight.）。
試験ポイント覚え方：see は ee（二つの目）で「見る」。海は sea（ea）。動作「見る・分かる」なら see、水の「海」なら sea。
発展恋愛の慰めの言葉としてよく使われる "There are plenty more fish in the sea."（海には他にもたくさん魚がいる＝出会いは他にもある）も、sea を使った有名な慣用句です。複合語 seasick（船酔いした）も、sea と結びついてよく使われる語です。動詞 oversee（監督する・取り仕切る）は see を語根に持ち、「上から見渡す」というイメージから「管理・監督する」の意味に転じた語です。形容詞 seaworthy（航海に耐えうる・耐航性のある）は、船が海を渡るのに十分な状態であることを表す専門的な語です。複合語 seaside（海辺・海岸沿い）も、観光地や住宅地の描写でよく使われる語です。動詞 foresee（予見する・予測する）も see を語根に持ち、将来を見通す力を表す語として使われます。

まとめ

  • sea と see は同音 /siː/
  • sea＝名詞「海」。at sea（途方に暮れて）/ sea level / the high seas
  • see＝動詞「見る・分かる」。see through/see off/see toなど句動詞が豊富
  • I see.は「見える」でなく「なるほど・分かりました」の相づち

A. see

A. sea
